# Rozgar — Job Finder for Pakistan (UX Concept Demo)


Interactive working demo of the **Rozgar** UX concept: a job-finding app for
Pakistan where every employer is verified, every listing shows the real PKR
salary upfront, and applications never disappear into a black hole.


## Demo
Live demo: https://abbasmomand98-jpg.github.io/rozgar-job-finder/


## What the demo does


- **Job search** — live text search across 13 realistic listings
- **Filters** — city (Lahore, Karachi, Peshawar, Islamabad), category
  (Delivery, Teaching, Office, Daily Wage, Tech, Retail, Healthcare),
  and monthly salary bands (Under Rs 30k → Rs 100k+)
- **Job detail view** — verified employer badge, PKR salary, requirements,
  shift/remote tags, and a **Report scam** button
- **3-step apply flow** — profile → experience → review & submit
- **Application tracker** — pipeline Submitted → Viewed → Shortlisted → Interview.
  Stages advance with real elapsed time (one stage per 6 hours); applications
  persist in `localStorage`
- **Urdu / English toggle** — full UI translation with RTL layout
- **Interview tips card** — appears once an application reaches Shortlisted


## Run it


Open `index.html` in any browser — no build step, no dependencies, single file.
